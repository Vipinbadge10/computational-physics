# Physics-Projects
This repository contains group of physics projects and divided into separate branches for each of the projects.

Note: The animation results can be found on Google-Drive.

- **Quantum Tunnelling using Analytical, Crank Nicolson and PINN**
- **N-Body-Simulation of Sun-Earth-Mars-Moon System**
- **Solving 2D Heat Equation using Finite Difference Method**
- **Steller Classification of SSDD17 dataset.**
- 
## Projects
#### 1. Quantum Tunnelling using Analytical, Crank, PINN method.
This project simulates quantum tunneling phenomenon using Crank Nicolson Numerical Method, and calculates transmission probability using Crank Nicolson, PINN and Analytical Method.
the simulation link for this project can be found on- https://drive.google.com/file/d/1lH6v4BPuNW9EA_696EYzBX_-s0SRVNTs/view?usp=drive_link
Branch Link- https://github.com/Vipinbadge10/computational-physics/tree/2D-Quantum-Tunnelling-Simulation-using-Analytical%2C-Crank-Nicolson-and-PINN

#### 2. N-Body-Simulation of Sun-Earth-Mars-Moon System.
This project simulates a 2D N body Problem of Sun-Earth-Earth's Moon- Mars system and study the orbital eccentricity energy conservation of system with Mass Variation of Sun.
Simulation link for simulation output of N Body Simulation- (https://drive.google.com/file/d/1J2MrVHV9Bp4acA3YbPkk50ezqO7MoPqd/view?usp=sharing)

Branch Link - (https://github.com/Vipinbadge10/computational-physics/blob/N-Body-Simulation)


#### 3. Solving 2D Heat Equation using Finite Difference Method.
This project studies diffusion of heat in 2D spatial grid using Finite Difference Method and animating the result.

The animation file for Heat Equation can be found- (https://drive.google.com/file/d/1dyRJPvkbFp7dXPHU5d8djUMQ2W3BAKGm/view?usp=sharing)

Branch Link-
(https://github.com/Vipinbadge10/computational-physics/blob/2D-Heat-Equation)

#### 4. Steller Classification of SSDD17 dataset. 
This project make use of classification algorithms and optimize it on SSDD17 Datasets for Steller Classification for better accuracy. 

The source code for this file can be found on Steller Classification branch- (https://github.com/Vipinbadge10/computational-physics/blob/Steller-Classification)
